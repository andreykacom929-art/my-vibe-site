# AGENTS.md — инструкции для агентов и разработчиков

Этот файл читается автоматически в начале работы над репозиторием. Он короткий, детали — по ссылкам.

## Обязательный контекст перед любой правкой
1. `README.md` — философия разработки и стандарты анимации (источник истины по правилам).
2. `REFERENCE_SOURCES.md` — какие репозитории-эталоны проверены, какие файлы использовать как образец и для какого правила.

## Жёсткие правила (из README.md, коротко)
- Код по `Airbnb JavaScript Style Guide` + архитектурным гайдлайнам Vercel, без легаси-методов.
- Логика данных отделена от логики анимации; динамика — в кастомных хуках.
- Только spring-физика, никаких дефолтных линейных анимаций. Микро-взаимодействия 150–200 ms, тяжёлые объекты — медленнее и с инерцией.
- Сложный скролл — GSAP `ScrollTrigger`. Обязательно: `will-change: transform` на анимируемых слоях и `kill()` таймлайнов при размонтировании (`gsap.context()` + `ctx.revert()`).
- Никаких шаблонных карточек: асимметрия, fluid typography, отступы от viewport.
- Сначала скелет и контент, потом микро-взаимодействия.
