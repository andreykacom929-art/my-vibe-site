# Философия разработки и стандарты анимации
Обучение агента: При разработке этого сайта используй в качестве контекста и эталона кода форки репозиториев airbnb/javascript, vercel/style-guide, codse/animata, radix-ui/primitives и Thakuma07/Truus.co-Awwward-Website из моего GitHub-профиля.
## 1. Качество кода и архитектура
- Пиши код строго по стандартам `Airbnb JavaScript Style Guide` и архитектурным гайдлайнам `Vercel`. Не используй легаси-методы.
- Разделяй логику данных и логику анимации. Все динамические значения выноси в кастомные хуки (React Hooks).

## 2. Стандарты анимации и инженерия движения
- Забудь про дефолтные линейные анимации. Используй только естественную физику движения (`spring physics`).
- Всегда закладывай "чувство веса" для элементов: тяжелые объекты двигаются медленнее и имеют большую инерцию, мелкие элементы (микро-взаимодействия) должны быть резкими и отзывчивыми (тайминг 150-200ms).
- При работе со сложным скроллом используй архитектуру `ScrollTrigger` от GSAP, но всегда предусматривай производительность: используй `will-change: transform` в CSS для анимируемых слоев и делай `kill()` для таймлайнов при размонтировании компонентов для предотвращения утечек памяти.

## 3. Визуальный стандарт и сетка
- Избегай стандартных шаблонных карточек. Используй асимметрию, адаптивную журнальную верстку (Fluid Typography) и динамические отступы, завязанные на размер экрана (viewport-based spacing).
- Анимация должна дополнять контент, а не отвлекать от него. Сначала строй прочный скелет сайта, затем «оживляй» его микро-взаимодействиями.
